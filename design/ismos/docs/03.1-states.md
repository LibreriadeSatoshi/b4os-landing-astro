# 03.1 States

*Settled. Behaviour by state and theme. One row per state; same columns every row.*

## Interface states

| State | Trigger | Appearance | Behaviour | Token |
|---|---|---|---|---|
| Default | — | Ink on Paper; buttons Ink with Paper type; cards with a 1 px hairline | — | `surface`, `text`, `action`, `hairline` |
| Hover | Pointer over | Card border darkens to Ink; link turns Logwood 800 | Nothing moves, lifts or scales | `text`, `link-hover` |
| Focus | Keyboard focus | 2 px outline, 2 px offset | Visible on every control | `focus` (Mauveine; Weld in Hacker mode) |
| Selected | Tab or toggle chosen | Weight and position change, plus colour | Never colour alone; never a fill on an icon | `text`, `bar` |
| Error | Invalid input | 2 px Madder 800 border, Alert icon, message naming the fix | Message tied with `aria-describedby` | `alert` |
| Empty | Nothing to show | A true sentence and one next step with a number in it | No illustration, no sad face | `text`, `text-muted` |
| Offline | No connection | Its own screen, plain sentence, saved lessons listed | Never a red banner or a toast; never an error state | `text`, `surface` |
| Disabled | Not available | Logwood 600 label, Ink-ramp border | Placeholder and disabled only, never body copy | `logwood-600` |

## Course card states

| State | Facts line reads | Token |
|---|---|---|
| Default | *Self-paced · 5 lessons · 3 h* | `text-muted` |
| In progress | *2 of 5 · continue* | `text-muted` |
| Finished | *Finished · record available* | `text-muted` |
| Saved offline | *Saved for offline · 4 MB* | `text-muted` |

## Progress states

| State | Appearance | Sentence |
|---|---|---|
| Started | 6 px Mauveine fill on Logwood 200 track; count *5 of 8* | *Three lessons left. Next: keys and backups.* |
| Not started | Empty track; count *0 of 6* | *Not started. The first lesson is nine minutes.* |
| Returning | Unchanged bar | *You are on lesson 3 of 8. Nothing has changed since you were last here.* |

Zero progress is an empty bar and a plain sentence, never a warning colour, never a nudge.

Every surface that ships is checked in both themes and in every language it ships in.
