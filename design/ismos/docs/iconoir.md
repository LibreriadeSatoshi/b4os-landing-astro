# Iconoir

Accepted October 2026. Forty icons from Iconoir (MIT licence, iconoir.com, npm `iconoir@7.11.0`): the twenty interface icons mapped to their Iconoir equivalents, then twenty for learning content. Single ink: Ink `#000000`, 1.5 px stroke, round caps, as Iconoir draws them. Iconoir replaces the original hand-drawn set entirely (no mixing). Same rules as before: line only, one ink, label by default, 20 px minimum, never in a badge or tile. Never use: graduation-cap, trophy, medal, crown, star, rocket. See 03 Specification, Icons.
