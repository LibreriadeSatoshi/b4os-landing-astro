# 09 Release

*Working. When it is done.*

## Pre-release checklist

- [ ] The mark is placed from the file, Ink or Paper, ≥ 20 px, with 0.25 M clear space.
- [ ] Every colour is a hex value from 03; no tag carries a colour; courses show their tags.
- [ ] Every text pair is in the PASS rows of 06; body text reaches 7:1 where the palette allows.
- [ ] Text on any dark colour is white, never off-white.
- [ ] Type uses Literata, Plex Sans and Plex Mono (or their script companions) at scale values only; no Light weight; Bricolage Grotesque only in the wordmark.
- [ ] Spacing, rules, corners, shadows, z-index and motion come from the token sets.
- [ ] Every state carries colour, an icon and a word. Icons are Iconoir, regular, one ink.
- [ ] Every language it ships in exists as an original; Arabic is mirrored right to left; both themes are checked.
- [ ] Every figure has a denominator; no invented number; placeholders listed.
- [ ] The copy passes the nine voice rules in 05: no banned word, no "learners" or "users", no geographic or demographic labels, no emoji, no exclamation mark in interface copy.
- [ ] AI-made material carries the AI label.
- [ ] Tested on a 360 px screen, a year-old Android, 3G and the longest string in any language.

## Open items

### From the palette change

1. **Name collisions.** The palette reuses *Indigo* and *Madder* for new values (`#2A2550`, `#FF7700`). Retire the old hex values everywhere (former Indigo `#22356B`, Madder `#A8341F`, Ochre `#B08028`, Malachite `#2F6B4F`), including Discord roles and old templates.
2. **STREAK.** The colour rules show a STREAK status tag and name streaks as a Weld use; 05 and the progress rules forbid streaks on the platform. Decide which holds.
3. **Neutrals.** Ink is `#000000` and Paper `#FFFFFF`; the former warm Ink `#14120F` and off-white Paper `#F5F3EE` are retired.
4. **Print colour.** CMYK values for the palette are not yet specified or proofed.

### Fabric imagery (removed for now)

5. **Fabric is out of the system for now.** The cloth imagery, its materials, the production recipe, frames cleared for type, sourcing rules and the textile image prompt are withdrawn until a palette-based version is agreed. Surfaces use Ink, Paper and flat colour blocks meanwhile. The source text remains in the Brand Style Guide, Part Two, sections 07 and 12.

### Languages

6. **Ten languages, one owner each.** Each language needs a native reader with the authority to hold a surface back. Today none is named.
7. **Right to left.** Modern Standard Arabic requires the mirrored layout described in 03. The separate RTL proposal was not accepted; this is the minimum Arabic needs.
8. **Fixed terms** in 05.1 exist for EN, ES, FR, PT; the other six languages need theirs.

### From the Style Guide

9. Tags need an owner who keeps the list short and consistent.
10. The mark has not been tested as stitching: test the four books at 20 mm and below; the open centre closes first.
11. The lockup and favicon exist as specifications, not supplied artwork files.
12. Offline packages: embedded fonts (now including script companions), image weight and a printable fallback for every lesson are unspecified.
13. Photographs of people in blog stories need a treatment. Teacher photos are settled (04 Rules, October 2026); their consent form is part of item 17.
14. Video, audio and diagrams have no rules.
15. Teacher and ambassador templates do not exist as files.
16. The AI tutor has no voice specification.
17. Consent has no process: no form, no record, no way to withdraw.
18. The credential question will come back.
19. No rule for a public disagreement.
20. Sign-in has no agreed flow (the auth proposal was not accepted).

**Priority:** the one-page version for ambassadors first, then language owners, then the tutor's voice, then the consent process.
