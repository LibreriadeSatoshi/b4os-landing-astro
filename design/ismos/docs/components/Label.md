# Label

The small uppercase IBM Plex Mono line above a block: section labels, course tags, and the AI disclosure label.

- `.ism-label`: 11 px, Medium, letterspaced 0.14em, `text-muted` (Logwood 800 on Paper).
- `.ism-label--ai`: the AI label. `text` colour (Ink on light, white on dark). Never Mauveine, never Weld. No chip, pill, box or border.
- `.ism-label--on-color`: Paper type on Mauveine, Indigo or Logwood blocks.
- **Provide:** the text. Uppercase is applied by CSS; write it in sentence case in the source so it translates.
- On the text column's margin, directly above or below what it describes.
