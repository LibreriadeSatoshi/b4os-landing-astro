# TextField

A labelled single-line input.

- **Provide:** a visible label, the input, and on error a message tied with `aria-describedby`.
- Default border: 1.5 px `border-input` (Logwood 700 in light mode, Logwood 400 in Hacker mode), `radius-4`, 48 px tall, `surface` inside.
- Error `.ism-field--error`: 2 px `alert` border (Madder 800), the Alert icon, and a message that names the fix. Never border alone.
- Errors say what happened and what to do next, with no codes in front of a student.
