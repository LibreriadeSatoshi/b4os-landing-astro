# Icon

ISMOS uses Iconoir (MIT licence, iconoir.com, `iconoir@7.11.0`): line icons on a 24 grid, 1.5 px stroke, regular style only, never filled. Files in `assets/Iconoir/`, ink `#000000`.

- **Provide:** an `<img>` or the `iconoir-react` component at 20, 24, 32 or 48 px, and a word beside it (8 px gap). An icon alone only for search, close, download.
- One colour per icon: Ink on light, white on dark (recolour the stroke or use `currentColor` in code), never two-tone.
- Interactive icons get a 44 px target.
- **Never use:** `graduation-cap`, `trophy`, `medal`, `crown`, `star`, `rocket`.
- **Don't:** badges, circles, fills, Iconoir's solid style, sizes below 20 px, icons from other libraries, emoji.
